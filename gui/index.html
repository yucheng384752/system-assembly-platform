前置步驟

目標伺服器 TPM 公鑰登錄

在開始選配 Kit 之前，請先取得目標伺服器的 TPM 公鑰，登錄後才能開放 Kit 選配與套件下載。

1
下載 TPM 設定包

壓縮檔含完整初始化腳本與公鑰匯出腳本，上傳至目標 Linux / Pi 伺服器後解壓。

2
在伺服器執行初始化（需 sudo，首次一次） sudo bash 01_tpm_full_setup.sh

自動安裝 swtpm、建立持久化 TPM 金鑰，完成後同目錄產生 machine-pubkey.pem。

3
上傳 machine-pubkey.pem

上傳後 Kit Composer 登錄 TPM 公鑰並開放後續操作。

未連接 Kit Composer 伺服器（需執行 node tools/serve-gui.cjs）
