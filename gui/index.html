前置步驟

目標伺服器 TPM 公鑰登錄

在開始選配 Kit 之前，請先取得目標伺服器的 TPM 公鑰，登錄後才能開放 Kit 選配與套件下載。

1
下載 TPM 公鑰腳本

將腳本傳至目標 Linux 伺服器執行（需先完成 TPM 初始化）。

2
在伺服器執行腳本 bash get-machine-pubkey.sh

執行後在同目錄產生 machine-pubkey.pem。若尚未初始化 TPM，請先執行 sudo bash 01_tpm_full_setup.sh。

3
上傳 machine-pubkey.pem

上傳後 Kit Composer 登錄 TPM 公鑰並開放後續操作。

✓ 已登錄 TPM 公鑰

未連接 Kit Composer 伺服器（需執行 node tools/serve-gui.cjs）
